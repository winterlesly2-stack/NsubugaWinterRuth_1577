# FreshBuy POS

The Flutter app lives in `main.dart`.

## Main Source

Open (main.dart) to vew the app. In VS Code, press `Ctrl+P` and enter `fieldnote_pos/lib/main.dart` to open it quickly.

## Run And Check

Use **Terminal > Run Task** and choose a FreshBuy task, or run these commands from `fieldnote_pos/`:

```powershell
flutter run
flutter analyze
flutter test
```

`flutter run` will let you select a connected device if more than one is available.

## GitHub

The Git remote is configured as `origin`. Use the VS Code **Source Control** view to review and stage changes.
